# MIT and public source publication

Decision date: 2026-10-16. At the project owner's request, first-party game
code and project-owned assets default to MIT, except narrower file notices.
The copyright holders are recorded in LICENSE and NOTICE. Dependencies,
third-party content and model weights retain their upstream terms. Previously
distributed versions retain their delivered licenses.

Publish current source as one initial commit in EmperyWorld/EmperyWorldGame,
without old history, local service configuration, credentials, save data,
models, runtime-generated media, caches or GitHub Actions workflow files.
The source includes the existing generation pipeline and example service
configuration; source publication is not a hosted game deployment.
