# Контроль, рывок, самонаведение

## Зачем

После волн спины/казни/рассечения и лука/яда/метки именованные навыки всё ещё не совпадали с фантазией: «пригвоздить» не замедлял, «удар щитом» не станил, «исчезающий удар» работал стоя, «змеиная стрела» могла промахнуться.

## Что изменилось

Числа: `packages/shared/src/combat-tactics.ts`.

`tactic` — модификатор удара. `control` — отдельное YAML-поле, чтобы `frost_nova` могла быть **cleave + pin**.

| Механика | Навыки | Правило |
|---|---|---|
| `control: pin` | pin_down, ice_lance, frost_nova | Скорость ×0.4 на **2.8с**. Nova вешает pin на все попадания залпа. |
| `control: stun` | shield_bash | Стан **1.6с**, **только со щитом**. Без щита — урон, стан не вешается, CD/MP тратятся. |
| `tactic: vanish` | vanishing_strike | Только из рывка (`dashing`). Иначе скилл **не тратится**. Бонус урона/точности/крита. |
| `tactic: seek` | serpentine_arrow, shadow_strike | Гарантированное физ. попадание (как charge). |

Стан на мобе: не ходит, не бьёт overlap и не бьёт disconnect-призрака. Pin — ходит медленнее, урон касанием остаётся.

Клиент: тосты STUN / PIN / «Нужен рывок» / РЫВОК / НАВОДКА; тинт жёлтый/голубой; снапшот шлёт `speed` + `control`.

## Как проверить

1. Воин 5+ со щитом: `удар щитом` — STUN, моб стоит. Без щита — урон, без стана.
2. Лучник 32+: `пригвоздить` — PIN, моб ползёт. Мистик: `ледяное копьё` / `морозная нова` тоже pin (нова — пачка).
3. Разбойник 17+: `исчезающий удар` стоя — «Нужен рывок», CD нет. Из рывка — РЫВОК.
4. Разбойник 5+ / лучник 36+: `теневой удар` / `змеиная стрела` не промахиваются (НАВОДКА).
