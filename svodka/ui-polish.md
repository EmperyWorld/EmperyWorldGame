# Сводка: шлифовка HUD и оверлеев

## Дата
2026-09-15

## Почему

HUD читался как черновик: подсказка — стена WASD-текста (ещё и перезаписывалась при входе в игру), графика спрятана в панели выживания, панели закрывались только Esc/кнопкой, кнопки сумки/навыков не показывали «открыто».

## Что изменилось

| | Было | Стало |
|---|---|---|
| затемнение панелей | клик мимо — ничего | закрывает инвентарь, навыки, путь, лавку, рацию, кузницу, жильё, станцию |
| лавка, подтверждение продажи | клик по фону закрывал всё | как Esc: сначала сброс «продать всё» |
| кнопки I / K / T / R | без состояния | `.open` + `aria-pressed` |
| `#hud-hint` | длинная строка, JS её затирал | статичные `<kbd>`: ход / удар / разговор / вход·рация / рывок |
| графика | только в выживании | чип `#hud-gfx` справа вверху, цикл как в панели |
| меню | «Меню · Esc» | «Меню» + чип Esc |
| логин | плейсхолдеры без label | «Логин» / «Пароль» |
| фокус с клавиатуры | почти не видно | золотое кольцо `:focus-visible` |
| тосты | `top: 78px` | `96px`, ниже верхней полосы |

Полоски HP чуть выше (17px). Курсор `pointer` на затемнении, на панели — обычный.

Не трогали: смерть, диалог, Phaser-мир, раскладку инвентаря.

## Проверка

`pnpm --filter @empery/client typecheck` и `pnpm --filter @empery/client test`.

Живой Phaser в браузере в этой сессии не гонялся: нет browser MCP. Нужен жёсткий refresh клиента (`start-all` без HMR).
