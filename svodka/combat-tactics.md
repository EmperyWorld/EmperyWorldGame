# Боевая тактика: навыки делают то, что написано

Следующая волна (лук / яд / метка): `svodka/combat-ranged.md`.
Контроль / рывок: `svodka/combat-control.md`.
Именованные AOE / добивания / костёр: `svodka/combat-named.md`.


## Зачем

Активные навыки жили только как `damageMultiplier` / `critBonus` в YAML. «Удар в спину» не требовал спины, «Казнь» била полных HP, «Рассечение» било одну цель. Волны рендера это не чинили.

## Что изменилось

Источник чисел: `packages/shared/src/combat-tactics.ts`. Статы по-прежнему в YAML; клиент только рисует флаги сервера.

| Tactic YAML | Навыки | Правило |
|---|---|---|
| `backstab` | backstab, garrote | Спереди навык **не тратится**. Спина — полный бонус. Фланг — слабее. |
| `execute` | execute, judgment_cut, heartseeker | Только при HP цели **≤35%**. Гарантированный крит. Иначе навык не тратится. |
| `cleave` | cleave, shockwave, blade_flurry, reaper_waltz, flame_burst, chain_lightning, frost_nova, spark_cascade, nova_ruin | До **4** целей. Основная — полный урон навыка, остальные **60%** splash. |

Одиночные скиллы больше не размазывают моды на всю пачку в радиусе. Обычный мили-бейсик по-прежнему задевает нескольких.

Дополнительно:

- **Позиция** на мили: фланг ×1.08, спина ×1.16 (лук/магия без позиционного бонуса).
- **Комбо**: окно 1.6 с, до 6 ударов, +5% урона за хит после первого. Промах сбрасывает.
- **Выносливость удара**: бейсик −16, скилл −32 (порог скилла 20). Усталость (≤100) режет точность и урон.
- **Рывок**: i-frame больше не глотает удар молча — сервер даёт **идеальный уворот** + XP + немного выносливости.

## Как проверить

1. Разбойник: `backstab` в лицо моба — тост «Нужна спина или фланг», CD не сел. Зайти за спину — «СПИНА».
2. Воин 25+: `execute` по полному HP — «Цель слишком жива». Добить до трети — «КАЗНЬ» + крит.
3. `cleave` / `flame_burst` в пачку — несколько цифр, на неосновных `SPLASH`.
4. Серия попаданий без паузы — `x2`…`x6` над героем.
5. Рывок сквозь моба — `PERFECT`, урон не проходит.

Клиент после удара подтягивает выносливость из combat-дельты (`stamina` в `CombatPlayerDelta`).
