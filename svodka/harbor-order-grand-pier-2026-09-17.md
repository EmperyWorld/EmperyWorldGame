# Сводка: порядок в порту + главный причал + видимость под аркой

Дата: 2026-09-17

## Цель

1. Логичная расстановка построек/объектов порта (не «побросано»).
2. Вместо «ворот в море» — длинный каменный причал, на котором рыбачат.
3. Проход через портовую арку: игрок виден (не рисуется под всем спрайтом).

## Что сделано

### Набережная (суша, З→В)
- Таможня / складской двор → рыбный ряд → карты / колокол → капитан / судовая лавка → трактир докеров → канаты / смотровая / маяк.
- Охрана арки: башни + посты + баннеры севернее стены (ty 48).
- Кран на борту причала (ty 51), не среди построек.

### Главный причал
- Каменная ось tx60–64, ty51–55 + боковые швартовы.
- Два `prop_pier_long` по оси проёма + боковые `prop_pier`.
- Флот по бортам; центр причала свободен.
- Ambient: рыбаки на tx62 («Клюёт!», «Сеть закинул.»); Ульф у fishmonger.

### Видимость под аркой
- `behindOcclusionStrip('arch')`: sortInset ≈ mid-span (не южный край спрайта).
- `resolvePropDepth`: для arch bias −0.0024.
- Арка size 220 (меньше overhang в воду).

### Verify
- vitest: prop-colliders / haven-city-gates / placement (HQ snipers + fisher colossus) — green.
- AABB: остаточные butcher/gardener/informant и cobbler/colonnade — вне порта, не трогали.
- `generate:maps` stamp `7edb8a6e093e`, preview `:5180`.

## Как проверить

1. http://localhost:5180/ → юг Haven, tx≈62.
2. Через арку выйти на длинный причал; рыбаки на оси.
3. Игрок в проёме арки виден (не «под текстурой»).
4. Набережные постройки стоят зонами, не кучей в воде.
