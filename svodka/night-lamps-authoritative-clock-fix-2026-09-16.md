# Night lamps lighting fix (authoritative clock aligned)

## Симптом
- Ночью фонари в Гавани выглядели как "не светят" или почти не давали ореол.

## Причина
- Часть визуала фонарей/окон в `location-decor` переключалась только по `havenSchedule.restActive`.
- Если schedule приходил позже/неровно, а `world_time` уже показывал ночь, фонари оставались в дневной яркости.
- Дополнительно порог и сила `DayNightLights` были слишком консервативны для безопасной городской ночи.

## Исправление
- `apps/client/src/day-night-overlay.ts`
  - для `outdoor` отключен ColorMatrix-проход (остается overlay veil), чтобы локальные лампы могли реально "пробивать" ночь;
  - ColorMatrix сохраняется для `indoor/dungeon`.
- `apps/client/src/sprites/location-decor.ts`
  - добавлен fallback на authoritative `world_time` (`getWorldGameHour()`) для ночного режима окон/фонарей;
  - усилена ночная яркость ламп (`2.1` вместо `1.7`), дневная подложка поднята до `0.72`;
  - `lampGlow` и `brazierGlow` подняты в слой выше day-night overlay (`Depth.DayNightOverlay + ...`) и переведены в `ADD`, чтобы свет действительно "пробивал" ночной veil.
  - после полевого фидбека "прожекторы" форма ореолов изменена с кругов на эллипсы с меньшей интенсивностью, чтобы свет выглядел как уличная подсветка, а не spotlight.
- `apps/client/src/day-night-lights.ts`
  - порог включения снижен: `darkness < 0.12` (было `0.18`);
  - увеличены радиусы/альфы baked light blobs для warm/tech источников;
  - итоговая сила света скорректирована до `min(0.92, 0.18 + (darkness - 0.1) * 1.12)` (баланс между читаемостью и "не прожектором").

## Результат
- Ночные фонари стабильно зажигаются синхронно с серверным временем.
- Даже в мягкой safe-zone ночи ореолы читаемы и не "пропадают".
