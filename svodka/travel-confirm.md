# Сводка: переход локации по кнопке

## Дата
2026-09-15

## Почему

Авто-overlap портала ставил `travelInFlight` и ждал `onTravelResult`. Если HTTP висел или сцена сменилась в `try/catch`, лок не снимался — выйти нельзя до перезапуска клиента.

## Как теперь

Стоять на зелёном пэде и подтвердить:

- **R** на пэде (иначе R — рация)
- HUD **«Войти»**
- клик по пэду (игрок всё равно должен стоять на нём)

E / геймпад A — только разговор. NPC на пэде больше не запускает `/travel`.

Авто-вход убран. `travelInFlight` сбрасывается по ответу HTTP или через 10 с (watchdog). `travelBusy` с таймаутом 10 с; ответ «Вы уже здесь» — ресинк сейва.

## Проверка

```bash
pnpm --filter @empery/client test -- src/game/systems/portal-pad.test.ts
```

`pnpm start:all` без HMR — нужен перезапуск.
