# Сводка: HUD основной игры

## Дата
2026-09-15

## Почему

После панелей остался сам боевой каркас: слева куча строк (локация, часы, «● Состояние: норма»), снизу английские P.Atk и десяток пилюль рядом с квестом, хотбар только с клавиатуры, чат постоянно спорит с миром.

## Что изменилось

| | Было | Стало |
|---|---|---|
| состояние | всегда «норма», сырые % и `critical` | чип «Состояние» / имена дефицитов; шкалы; «критично» по-русски |
| панель выживания | `top: 78px`, дубль графики | под верхней полосой; клик снаружи / Esc; графика только в чипе HUD |
| место и время | две строки | одна строка |
| квест | «Квест: …» под заголовком «Квест» | без повтора префикса |
| статы | 8–12 пилюль P.Atk / Acc | Атк / Защ / Маг / М.защ, остальное в «ещё» |
| хотбар | только 1–9 | клик / Enter по слоту → тот же `queueSkill` |
| чат | всегда плотный | притушен, короткий лог; Enter в шапке фокусирует ввод |

Не трогали: инвентарь, диалог, Phaser-мир.

## Проверка

`pnpm --filter @empery/client typecheck` и `pnpm --filter @empery/client test`.

Живой Phaser в браузере не гонялся (нет browser MCP). Нужен жёсткий refresh клиента.
