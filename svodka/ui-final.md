# Сводка: финальная шлифовка UI

## Дата
2026-09-15

## Почему

После HUD остались англицизмы в панелях (P.Atk, adena, GS) и «черновые» кнопки смерти / диалога / рации. Игрок видит две системы подписей.

## Что изменилось

| | Было | Стало |
|---|---|---|
| статы | P.Atk / Acc в сумке, лавке, навыках | общие русские ярлыки (`stat-labels.ts`) |
| валюта | `adena` в лавке, кузне, рации, квесте | «адены» |
| сила предмета | GS | «сила» |
| смерть | кнопки без type, в куче | `.death-actions`, type=button |
| диалог / рация | «Esc · Закрыть», «Закрыть [R]» | «Закрыть» + чип клавиши |
| конь | фиолетовый `.active` как автоатака | `.open` + `aria-pressed` |

Сравнение шмота пропускает ключи без числа — иначе новые ярлыки навыков ломали бы дельту.

Не трогали: раскладку инвентаря, Phaser-мир.

## Проверка

`pnpm --filter @empery/client typecheck` и `pnpm --filter @empery/client test`.

Живой Phaser в браузере не гонялся. Нужен жёсткий refresh клиента.
